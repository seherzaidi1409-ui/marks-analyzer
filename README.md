# Marks Analyzer

A Python program that analyzes student marks and provides performance insights.

## Features
- Input student marks
- Calculate percentage
- Find highest score
- Find lowest score
- Calculate average marks
- Identify strongest subject
- Identify weakest subject

## Concepts Used
- Lists
- Functions
- Loops
- Conditional Statements
- User Input

## Technologies Used
- Python

## How to Run

```bash
python marksanalyzer.py
```
